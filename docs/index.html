Key Features

🔄

Checkpoint Persistence

SQLite-based state recovery. Resume any failed run from exactly where it stopped. Never lose progress.

🧑‍💼

Human-in-the-Loop

Interactive CLI approval with Rich formatting. Review and approve/reject headlines before video generation.

⚡

Error Recovery

Each stage handles failures gracefully. Bad feeds? Skipped. Failed video? Logged. Pipeline continues.

📰

RSS Integration

Configurable feed sources for AP, Telangana, and India tech news. Keyword filtering and deduplication.

🎬

Video Generation

Mock mode for demos and testing. Hook into real APIs (Synthesia, D-ID, HeyGen) for production.

📊

Audit Trail

Every approval decision is logged with timestamps. Full pipeline state history in SQLite.

Quick Start

Get running in under 2 minutes

1

Clone & Install

Terminal 
git clone https://github.com/nagarjunak-pixel/langgraph-localai-tv.git
cd langgraph-localai-tv
pip install -r requirements.txt
2

Configure Environment

Terminal 
cp .env.example .env
# Edit .env with your API keys (optional — works without them)
3

Run the Pipeline

Terminal 
# Interactive mode (with human approval)
python pipeline.py

# Auto-approve mode (for demos/testing)
python pipeline.py --auto

# Resume a failed run
python pipeline.py --resume abc12345

API Reference

pipeline.py

run_pipeline(auto_approve=False, resume_run_id=None)

Execute the full 3-stage pipeline. Returns final PipelineState.

nodes/headline_fetcher.py

fetch_headlines(feeds=None, max_headlines=10)

Fetch and deduplicate headlines from RSS feeds.

filter_headlines(headlines, keywords=None)

Filter headlines by keyword match.

nodes/video_generator.py

generate_video_script(headline)

Create a video script from a headline dict.

batch_generate_videos(headlines)

Generate video segments for all approved headlines.

nodes/bulletin_compiler.py

compile_bulletin(videos, bulletin_title=None)

Compile video segments into a final news bulletin.

format_bulletin_text(bulletin)

Format bulletin as readable text output.

checkpoints.py

CheckpointStore(db_path="./checkpoints.db")

SQLite checkpoint persistence. Methods: save(), load(), list_runs(), invalidate().

human_approval.py

request_approval_cli(headlines)

Interactive CLI approval with Rich tables.

request_approval_auto(headlines)

Auto-approve for CI/CD and testing.
